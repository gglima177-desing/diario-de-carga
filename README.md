# Diário de Carga

App de treino de musculação para o celular: registra carga, repetições, aquecimento, séries até a falha, cardio e mostra a evolução semana a semana. Funciona offline e guarda os dados só no aparelho.

## Como instalar no Android

1. Abra o endereço do app no Chrome.
2. Toque nos três pontos do Chrome e em **Instalar app** (ou **Adicionar à tela inicial**).
3. Abra o app pelo ícone. Depois da primeira abertura com internet, ele abre sem internet também.

## Seus dados

Os treinos ficam no armazenamento do navegador do aparelho. Se você limpar os dados do Chrome ou desinstalar o app, o histórico some. Na aba **Histórico**, use **Backup (JSON)** de vez em quando e **Importar backup** para restaurar.

## Atualizações

Quando o app for atualizado, a nova versão aparece na segunda vez que você abrir o app com internet.
